Method

For each MethylLlama sample, cosine similarity was computed against every AltumAge sample in the same split over all 19,608 shared CpG sites. The nearest neighbour was taken as the candidate match.

Cosine ≥ 0.9999 = identical biological sample. Direct ID matching was also attempted using the sample index names.
