The Problem — What Are We Trying to Learn?

DNA Methylation (β values)

Each CpG site has a methylation level β ∈ [0, 1].
Low β = unmethylated. High β = methylated.

These patterns encode tissue identity, biological age, and disease state.

The Scale Challenge

  • 450k / 850k CpG arrays → only 49,156 high-quality type-III probes used
  • Each sample = a vector of 49k real numbers in [0,1]
  • 169,120 samples × 49,156 CpGs = ~21 GB dense matrix

Goal: Learn a Universal Methylation Encoder

  • Pretrain on 170k samples (no labels needed)
  • Encode full methylome → single CLS vector
  • Fine-tune on downstream tasks (age prediction, tissue classification)
Key insight: If we can predict 50% of CpGs from the other 50%, the encoder must have learned meaningful biological structure — not just memorized noise.

  • Layers: 4

  • FFN intermediate: 320 (SwiGLU)
  • Total encoder params: ~2.4M

Decoder

  • Linear(256 → 256) → LayerNorm → GELU → Dropout

  • ProjectionHead: MLP(256→128), L2-norm → contrastive (optional)
  • AgeHead: MLP(256→1) → age prediction (optional)

ScaleAdapt — How Beta Values Are Encoded

Formula

For each β ∈ [0, 1] and k = 1..48 basis functions:

features_k = [sin(β × f_k), cos(β × f_k)]
output = Linear(96 → 256)(concat all features)

Frequencies f_k are initialized from N(0, 2π × 2.0) and learned during pretraining — the model decides which resolution of β variation matters biologically.

Special Token Routing

  • β = -1 → MASK token embedding
  • β = -2 → CLS token embedding
  • β = -3 → SEP token embedding
  • β = -4 → PAD token embedding
  • β ≥ 0 → sinusoidal encoder (real methylation value)

Why Not MLP?

  • MLP: two scalars 0.85 and 0.87 produce similar hidden states — small difference gets lost
  • ScaleAdapt: high-frequency basis functions create large angular differences for small β differences
  • Same principle as positional encoding in NLP — but for continuous values

basis_scale = 2.0

Upstream model used 1.5 (for scRNA, range 0–10+).

Methylation β ∈ [0,1] is a much tighter range → need higher initial frequencies to resolve fine differences.

Value of 2.0 tuned for methylation domain.

Loss Function

L = MSE(β̂non-input, βnon-input)

Only on held-out CpGs, NaN positions excluded

Why This Works

  • Forces encoder to learn co-methylation patterns across the genome
  • CpGs in the same region are correlated — encoder learns this structure
  • No labels needed — fully self-supervised on 170k samples
  • CLS vector must summarize the full methylome to reconstruct it

Optional Extensions (disabled for now)

  • Contrastive (InfoNCE): Two random 50% views of same sample → positive pair. Improves CLS quality
  • Age supervision: AgeHead on CLS forces age encoding into the representation

The Hypothesis

Methylation data is highly structured — CpGs in the same genomic region are strongly correlated. A small model with enough data may capture this structure as well as a large model.

Data > Parameters for Methylation

  • 170k samples cover broad tissue diversity
  • 49k CpGs = rich input signal per sample
  • MethylGPT (64D, ~6M) achieved strong results on 170k samples
  • Our small model: 4× more layers, RoPE, SwiGLU, ScaleAdapt

Practical Benefit

  • 4 GPUs → 300 epochs in ~24h (vs ~5 days for full model)
  • Faster iteration → more experiments
  • If small ≈ full: deploy smaller, cheaper model

Summary

Data Pipeline

  • 169k GEO samples, 49k type-III CpG probes
  • Stored as 21 GB h5ad, read lazily row-by-row
  • Random 50/50 split per epoch (WCED collator)
  • 8.5% NaN rate handled by masking

Architecture (Small)

  • 4 layers × 256D × 4 heads (SwiGLU FFN)
  • RMSNorm Pre-LN + RoPE (no position table)
  • ScaleAdapt sinusoidal β encoder (48 basis, scale=2.0)
  • Learned cpg_scale parameter (init=0.1)
  • WCEDDecoder: CLS → Sigmoid → 49k β̂

Key Changes vs SCBert

  • Pre-LN + RMSNorm → stable training
  • SwiGLU → more expressive FFN
  • RoPE → no position embedding table
  • ScaleAdapt → better β resolution
  • No monkey-patching → clean codebase

Experiments Running

  • Small model (5M) on 170k samples → fast, efficient
  • Full model (95M) on 170k samples → upper bound
  • Hypothesis: small ≈ full for methylation data
  • Smoke test PCC 0.877 confirms pipeline is correct
