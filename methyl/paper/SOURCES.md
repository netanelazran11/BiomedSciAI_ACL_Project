# Where the manuscript lives, and which copy wins

**The live Overleaf project is the source of truth.** It is what renders, and it
is what gets submitted. Its local mirror is:

    methyl/outputs/overleaf/MethylLlama_Publication/

`methyl/paper/` is **not a second manuscript.** It is the git-tracked staging
area: text is authored and versioned here, then ported into the Overleaf mirror.
Anything written here that has not been ported does not exist as far as the
paper is concerned.

| | `methyl/paper/` | `outputs/overleaf/…` | live Overleaf |
|---|---|---|---|
| role | staging + history | mirror of the truth | the truth |
| git | tracked | gitignored | — |
| Claude can write | yes | yes | **no** |
| ChatGPT/Codex writes | no | yes | yes |

Claude cannot reach the live project. "Claude updated the paper" therefore means
the mirror changed, and someone still has to push the mirror up to Overleaf.

## Why this replaced the previous rule

Until 2026-09-01 both copies were edited as live peers, each model owning one.
That failed inside two days, in both directions at once:

  * Codex corrected the Results section in the Overleaf copy at 19:25 on 08-30,
    after `paper/` had been seeded from it at 16:59. Claude then audited the
    stale file and produced findings that were already fixed.
  * `paper/` meanwhile held the only copies of Methods (1,620 w), Discussion
    (502 w), and the Supplementary — so the Overleaf project, the thing that
    actually renders, was compiling with empty skeletons for all three.

A paper is one document, submitted once, and its sections constrain each other:
a provenance fix in Results has a matching claim in Methods. Splitting one
document across two live copies is a merge conflict scheduled for later.

## Working rule

1. Author in `paper/`, commit, then copy the changed sections into the mirror.
2. Never edit the same section in both copies in one sitting.
3. Run `bash paper/diff_sources.sh` **before** editing, not after.
4. Figures are generated by `scripts/paper_figures/*.py` into `figures/paper/`.
   That directory is canonical; both `.tex` trees hold copies of it.

## Checking

    bash paper/diff_sources.sh          # word counts, mtimes, per-section status
    bash paper/diff_sources.sh --full   # + unified diffs of anything that differs

The table prints both copies' mtimes side by side. An `overleaf/` timestamp
newer than its `paper/` twin is the warning sign that was missed on 08-30.
Figures are compared by drawn content and byte size, not by md5: matplotlib
stamps a `/CreationDate` into every PDF, so md5 reported identical figures as
stale on every run.
