# MethylLlama publication project

Staging area for the MethylLlama paper. The source of truth is the live Overleaf
project; see `SOURCES.md` for which copy wins and how to sync. Intentionally
separate from the M.Sc. thesis project.

## Overleaf

1. Upload `MethylLlama_Publication.zip` as a new project.
2. Set `main.tex` as the main document and compile with pdfLaTeX.
3. Invite supervisors using **Share** with **Can edit** access.
4. Use the Review panel and Track Changes for collaborative editing.

## Drafting convention

Only move a section from skeleton to populated status after its claims, numbers, citations,
and referenced artifacts have been checked. Keep source comments for internal drafting notes;
do not print unverified placeholders in the manuscript PDF.
