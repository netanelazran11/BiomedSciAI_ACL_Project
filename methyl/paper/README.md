# MethylLlama publication project

This is a general, self-contained Overleaf project for developing the MethylLlama paper
section by section. It is intentionally separate from the M.Sc. thesis project.

## Current status

- `sections/00_abstract.tex` — populated working draft
- `sections/01_introduction.tex` — populated working draft
- `sections/02_results.tex` — populated working draft
- `sections/03_discussion.tex` — empty skeleton
- `sections/04_methods.tex` — empty skeleton
- `sections/05_data_availability.tex` — empty skeleton
- `sections/06_code_availability.tex` — empty skeleton
- `sections/07_acknowledgements.tex` — empty skeleton
- `sections/08_author_contributions.tex` — empty skeleton
- `sections/09_competing_interests.tex` — empty skeleton
- `sections/10_supplementary_information.tex` — separate supplementary skeleton

The empty files contain only `%` comments and therefore do not print empty headings in the PDF.

## Overleaf

1. Upload `MethylLlama_Publication.zip` as a new project.
2. Set `main.tex` as the main document and compile with pdfLaTeX.
3. Invite supervisors using **Share** with **Can edit** access.
4. Use the Review panel and Track Changes for collaborative editing.

## Drafting convention

Only move a section from skeleton to populated status after its claims, numbers, citations,
and referenced artifacts have been checked. Keep source comments for internal drafting notes;
do not print unverified placeholders in the manuscript PDF.
