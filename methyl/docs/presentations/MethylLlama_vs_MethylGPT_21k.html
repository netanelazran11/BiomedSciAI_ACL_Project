The row-level GSM match reports a low count only because MethylGPT stores plain integer indices that don't preserve h5ad row order — a re-indexing artifact, not a split difference. One caveat — test-set filters. MethylGPT evaluates on the full 2,264 raw test rows. MethylLlama's pipeline additionally drops 115 (5.1%): 99 age outliers (age<0 or >120, e.g. −0.7, 144) + 16 duplicates → 2,149. Same split, minor filtering difference. For strict parity, evaluate both on the identical row set.
