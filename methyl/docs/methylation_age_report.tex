\section{Introduction}
DNA methylation provides strong signals for age prediction, but the data are high-dimensional and noisy. We use a Transformer-based foundation model (MethylGPT) to learn sample-level representations from CpG tokens and establish a stable 8K-CpG baseline. This baseline serves as the reference point for evaluating a proposed BMFM-RNA architecture.

\textbf{Pretraining data.} Large-scale methylation profiles (154,063 after QC) are used to learn general representations before downstream fine-tuning.

This model fits our data because methylation profiles contain structured CpG dependencies that benefit from self-attention, while pretraining on large-scale methylation data learns generalizable token representations. The pretrained Transformer transfers to the 8K-CpG setting, and the ResNet1D head maps learned embeddings to age.

\textbf{Fine-tuning data.} We fine-tune on 11,453 labeled samples, each represented by 8,000 CpGs per sample (M=8000), with ages spanning 0--100 years and multi-tissue composition (blood $\sim$47.2\%, brain $\sim$34.5\%, others $\sim$18.3\%).

\textbf{Fine-tuning task.} Predict chronological age from the Transformer embeddings using a ResNet1D regression head (Conv1D 3x3, 6x ResBlock1D, AdaptiveAvgPool1d, Dropout, Linear, Sigmoid) with MSE loss. The output is a normalized age in [0,1]. The baseline results are reported in Section 7.

\textbf{Architecture flow :} Pretraining applies MLM-style masked value prediction using the ExprDecoder; fine-tuning replaces the decoder with a ResNet1D age head that operates on Transformer outputs (excluding [CLS]) to produce a single normalized age prediction.

\section{Loss Function}
Pretraining uses masked MSE to reconstruct methylation values (MLM) with a 30\% mask ratio, along with a profile-level reconstruction objective. Fine-tuning uses MSE on normalized chronological age with no masking.


\section{Evaluation Plan}
We use a fixed 48/12/40 train/val/test split. Model selection uses validation MAE. The test set is used once per run for final evaluation. Generalization is assessed by repeating training with multiple random seeds (40--44). Metrics reported for age prediction include MAE, MedAE, RMSE, $R^2$, Pearson $r$, and Spearman $r$.

\section{Proposed Changes: BMFM-RNA Architecture}

We adapt the BMFM-RNA SCBert architecture for methylation-based age prediction. The original BMFM-RNA is a BERT-based foundation model for single-cell RNA-seq ($\sim$110M parameters). We scale it down to match our 8K-CpG input.

\begin{itemize}[leftmargin=1.5em]
\item \textbf{Reference:} \href{https://research.ibm.com/projects/biomedical-foundation-models}{\textbf{BMFM-RNA (IBM Research Project)}}
\item \textbf{Code:} \href{https://github.com/netanelazran11/BiomedSciAI_ACL_Project}{\textbf{GitHub Repository}}
\end{itemize}

\subsection{Tokenizer and Multi-Field Representation}

BMFM-RNA uses a \texttt{MultiFieldTokenizer} that handles multiple input fields (e.g., gene IDs and expression values). We adapt this for methylation by creating a custom tokenizer:

\textbf{Vocabulary construction.} We extract the 8{,}000 CpG site names (e.g., \texttt{cg00000029}, \texttt{cg00000108}) from the h5ad data file and build a vocabulary with 5 special tokens , followed by CpG site tokens (IDs 5--8004). Total vocab size: 8{,}005.

\textbf{Two-field input.} Each sample is represented as two parallel sequences:
\begin{enumerate}
\item \textbf{cpg\_sites}: Discrete token IDs $[3, s_1, s_2, \ldots, s_n, 2, 2, \ldots]$ where 3=[CLS], $s_i$ are CpG IDs, and 2=[PAD]
\item \textbf{beta\_values}: Continuous $\beta$-values $[0, \beta_1, \beta_2, \ldots, \beta_n, 0, 0, \ldots]$ in range $[0,1]$
\end{enumerate}

\textbf{Embedding combination.} Each CpG site $i$ is represented by combining both fields via element-wise summation:
\begin{equation}
\mathbf{h}_i = \mathbf{e}_{\text{cpg}}(s_i) + \mathbf{e}_{\beta}(\beta_i) + \mathbf{e}_{\text{pos}}(i)
\label{eq:embedding_sum}
\end{equation}
where $\mathbf{e}_{\text{cpg}}(s_i) \in \mathbb{R}^{512}$ is a learned CpG site embedding, $\mathbf{e}_{\beta}(\beta_i) \in \mathbb{R}^{512}$ is the output of a continuous value encoder (MLP that projects $\beta$-values to the hidden dimension), and $\mathbf{e}_{\text{pos}}(i) \in \mathbb{R}^{512}$ is the position embedding. The combined sequence is passed through a 6-layer Transformer encoder.

\subsection{Fine-Tuning Pipeline}

The pretrained encoder is fine-tuned for age regression:
\begin{itemize}[leftmargin=1.5em]
\item \textbf{Pooling:} Mean pooling over token outputs (skip CLS)
\item \textbf{Age head:} MLP (512 $\to$ 256 $\to$ 128 $\to$ 1) with LayerNorm, GELU, Dropout(0.2)
\item \textbf{Freeze strategy:} Encoder frozen epochs 0--4, unfrozen epoch 5+ with 10$\times$ lower LR
\item \textbf{Loss:} MSE on $z$-score normalized ages
\end{itemize}

\section{Discussion and Conclusions}

\subsection{Why BMFM-RNA Architecture for Methylation?}

The BMFM-RNA SCBert architecture offers several advantages for methylation-based age prediction:

\textbf{Multi-field tokenization.} Unlike standard approaches that treat methylation values as a flat vector, BMFM uses a dual-field representation: each CpG site is encoded as $\mathbf{h}_i = \mathbf{e}_{\text{cpg}}(s_i) + \mathbf{e}_{\beta}(\beta_i)$. The CpG ID embedding captures site-specific information (genomic context, regulatory role), while the continuous value encoder captures the methylation state. This separation allows the model to learn which sites are informative independently of their current methylation level.

\textbf{Continuous value encoding.} The $\beta$-value encoder uses an MLP to project continuous methylation values into the embedding space, rather than discretizing them into bins. This preserves fine-grained information that may be lost in quantization-based approaches.

\textbf{Self-attention over CpG sites.} The Transformer encoder learns pairwise relationships between CpG sites. Methylation patterns are known to be correlated across genomic regions (e.g., CpG islands, promoters). Self-attention can capture these long-range dependencies without explicit feature engineering.

\subsection{Why Pretraining Helps}

\textbf{Transfer learning from large-scale data.} The encoder is pretrained on  methylation profiles using masked value prediction (MLM). During pretraining, the model learns to reconstruct masked $\beta$-values from context, forcing it to understand the statistical structure of methylation patterns across diverse tissues and conditions. These learned representations transfer to the age prediction task.

\textbf{Pretrained components.} The checkpoint provides well-trained: (1) CpG site embeddings that encode site-specific properties, (2) $\beta$-value encoder that maps continuous values to meaningful representations, (3) Transformer layers that capture inter-site dependencies, and (4) position embeddings. Without pretraining, the model must learn all of this from the smaller fine-tuning dataset (11{,}453 samples), which is insufficient for a 23M parameter model.


\subsection{Key Implementation Changes}

Several critical modifications were required to achieve good performance:



\textbf{Optimizer configuration fix.} A critical bug was identified: PyTorch Lightning's \texttt{configure\_optimizers()} is called once at initialization. If encoder parameters are frozen (requires\_grad=False) at init, they are excluded from the optimizer. Simply setting requires\_grad=True later does not add them to the optimizer. The fix is to include all parameters in the optimizer from the start---frozen parameters receive no gradients and are skipped automatically.

\textbf{Mean pooling instead of CLS.} MLM pretraining does not train the [CLS] token to aggregate sequence information (unlike NSP in BERT). We use mean pooling over content tokens, which empirically works better for regression tasks after MLM pretraining.

\textbf{Z-score normalization.} Ages are normalized to zero mean and unit variance during training. This stabilizes gradients and improves convergence, especially important when the target range (0--100 years) differs significantly from typical neural network output scales.

\subsection{Results Analysis}

\textbf{BMFM-RNA performance.} Using the corrected pipeline with all 8{,}000 CpG sites and dropout=0.2, the model achieves Test MAE = 4.85 years and $R^2$ = 0.923. This outperforms MethylGPT baseline (MAE = 4.95 years, $R^2$ = 0.911) by 2\% in MAE and 1.2\% in $R^2$.

\textbf{Comparison with mean prediction.} The mean prediction baseline (predicting $\bar{y}_{\text{train}}$ for all samples) achieves MAE = 22.82 years. Both BMFM-RNA (4.85) and MethylGPT (4.95) reduce this error by approximately 78\%, demonstrating that both models learn meaningful age-predictive representations from methylation data.

\textbf{Overfitting reduction.} Increasing dropout from 0.1 to 0.2 reduced the train--test MAE gap to $\sim$2.6 years (train MAE = 2.21, test MAE = 4.85). Further regularization or data augmentation may continue to narrow this gap.

\textbf{Model capacity vs. performance.} Despite BMFM-RNA having 23M parameters compared to MethylGPT's 2M parameters, the improvement is modest (0.10 years). This suggests that methylation age prediction may be approaching a performance ceiling, or that additional model capacity requires more sophisticated training strategies to fully leverage.
