\section{Introduction}
DNA methylation provides strong signals for age prediction, but the data are high-dimensional and noisy. We use a Transformer-based foundation model (MethylGPT) to learn sample-level representations from CpG tokens and establish a stable 8K-CpG baseline. This baseline serves as the reference point for evaluating a proposed BMFM-RNA architecture.
\begin{itemize}[leftmargin=1.5em]
\item \textbf{Article paper:} \href{https://www.biorxiv.org/content/10.1101/2024.10.30.621013v2}{\textbf{MethylGPT (bioRxiv 2024)}}
\item \href{https://github.com/netanelazran11/BiomedSciAI_ACL_Project}{\textbf{BiomedSciAI ACL Project (GitHub)}}
\end{itemize}

\section{Baseline Architecture}
\textbf{Pretraining data.} Large-scale methylation profiles (154,063 after QC) are used to learn general representations before downstream fine-tuning.

This model fits our data because methylation profiles contain structured CpG dependencies that benefit from self-attention, while pretraining on large-scale methylation data learns generalizable token representations. The pretrained Transformer transfers to the 8K-CpG setting, and the ResNet1D head maps learned embeddings to age.

\textbf{Fine-tuning data.} We fine-tune on 11,453 labeled samples, each represented by 8,000 CpGs per sample (M=8000), with ages spanning 0--100 years and multi-tissue composition (blood $\sim$47.2\%, brain $\sim$34.5\%, others $\sim$18.3\%).

\textbf{Fine-tuning task.} Predict chronological age from the Transformer embeddings using a ResNet1D regression head (Conv1D 3x3, 6x ResBlock1D, AdaptiveAvgPool1d, Dropout, Linear, Sigmoid) with MSE loss. The output is a normalized age in [0,1]. The baseline results are reported in Section 7.

\textbf{Architecture flow (summary).} Pretraining applies MLM-style masked value prediction using the ExprDecoder; fine-tuning replaces the decoder with a ResNet1D age head that operates on Transformer outputs (excluding [CLS]) to produce a single normalized age prediction.

\section{Loss Function}
Pretraining uses masked MSE to reconstruct methylation values (MLM/MVP) with a 30\% mask ratio, along with a profile-level reconstruction objective. Fine-tuning uses MSE on normalized chronological age with no masking.

\section{Training Plan}
We first run a small hyperparameter sweep and select the best configuration using validation MAE only. Fine-tuning is initialized from pretrained weights. Training uses 100 epochs with an 80\% warmup phase and a final 20\% convergence phase. The best checkpoint is selected from epochs 81--100.

\section{Evaluation Plan}
We use a fixed 48/12/40 train/val/test split. Model selection uses validation MAE. The test set is used once per run for final evaluation. Generalization is assessed by repeating training with multiple random seeds (40--44). Metrics reported for age prediction include MAE, MedAE, RMSE, $R^2$, Pearson $r$, and Spearman $r$.

\section{Proposed Changes: BMFM-RNA Architecture}

We adapt the BMFM-RNA SCBert architecture for methylation-based age prediction. The original BMFM-RNA is a BERT-based foundation model for single-cell RNA-seq ($\sim$110M parameters). We scale it down to match our 8K-CpG input.

\subsection{Multi-Field Tokenization}

Each CpG site $i$ is represented by two parallel fields combined via element-wise summation:
\begin{equation}
\mathbf{h}_i = \mathbf{e}_{\text{cpg}}(s_i) + \mathbf{e}_{\beta}(\beta_i)
\label{eq:embedding_sum}
\end{equation}
where $\mathbf{e}_{\text{cpg}}(s_i) \in \mathbb{R}^{512}$ is a learned CpG site embedding and $\mathbf{e}_{\beta}(\beta_i) \in \mathbb{R}^{512}$ is the output of a continuous value encoder. The sequence is passed through a 6-layer Transformer encoder.

\subsection{Fine-Tuning Pipeline}

The pretrained encoder (MLM loss = 0.0013, PCC = 0.997 after 240 epochs) is fine-tuned for age regression:
\begin{itemize}[leftmargin=1.5em]
\item \textbf{Pooling:} Mean pooling over token outputs (skip CLS)
\item \textbf{Age head:} MLP (512 $\to$ 256 $\to$ 128 $\to$ 1) with LayerNorm, GELU, Dropout(0.1)
\item \textbf{Freeze strategy:} Encoder frozen epochs 0--4, unfrozen epoch 5+ with 10$\times$ lower LR
\item \textbf{Loss:} MSE on $z$-score normalized ages
\end{itemize}

\section{Discussion and Conclusions}

\textbf{BMFM-RNA adaptation.} The BMFM-RNA SCBert architecture successfully transfers to methylation age prediction. Using the correct pretrain$\to$finetune pipeline (frozen encoder with gradual unfreezing, MLP age head on mean-pooled outputs), the model achieves Test MAE = 4.87 years and $R^2$ = 0.924 on a 2{,}048 CpG subset.

\textbf{Comparison with baselines.} The BMFM-RNA result is within 10\% of Ridge regression (4.49 years) and MethylGPT (4.39 years), despite using 4$\times$ fewer CpG sites. This suggests the Transformer encoder learns efficient representations that capture the age signal in fewer features.

\textbf{Limitations.} (1) Single training run; multi-seed evaluation needed. (2) Full 8K CpG input not yet tested with the corrected pipeline. (3) Comparison uses different CpG subsets (2K vs 8K).
